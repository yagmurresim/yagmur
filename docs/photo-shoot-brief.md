# Yağmur Sanat Akademisi — Fotoğraf Çekim Brifing

Bu belge, profesyonel fotoğraf çekimi için hazırlanmış minimum shot list'i içermektedir.

> **ÖNEMLİ:** Çocukların görsellerinin web sitesinde ve sosyal medyada kullanımı için veli onay formu alınmalıdır. Bu madde production launch checklist'in zorunlu adımlarından biridir.

---

## Teknik Gereksinimler

- Format: RAW + yüksek çözünürlüklü JPEG
- Boyut: Minimum 4000px uzun kenar
- Renk profili: sRGB
- Teslim: Dışa aktarılmış + düzenlenmemiş ham dosyalar

---

## 1. Mekân

| Shot | Format | Öncelik |
|------|--------|---------|
| Akademi dış cephe / giriş | 3:2 horizontal, 16:9 | Yüksek |
| Giriş alanı / resepsiyon | Geniş plan | Yüksek |
| Genel sınıf atmosferi | Editorial geniş | Yüksek |
| Koridor / kapılar / tabelalar | Detay | Orta |
| Mimari detaylar / aydınlatma | Detay | Orta |

---

## 2. Resim Eğitimi

| Shot | Format |
|------|--------|
| Grup dersi — geniş plan | Horizontal |
| Öğretmen–öğrenci etkileşimi | 4:3 |
| Fırça tutan eller — detay | Kare / dikey |
| Boya / palet detayları | Kare |
| Tuval üzerinde çalışma | Horizontal |
| Öğrenci çalışmalarının dokümantasyonu | Flat lay |
| Over-the-shoulder çalışma görüntüsü | 4:3 |

---

## 3. Piyano Eğitimi

| Shot | Format |
|------|--------|
| Öğrenci + eğitmen birebir ders | 4:3 horizontal |
| Klavye üzerinde eller — detay | Horizontal |
| Yan açı piyano portresi | 4:5 dikey |
| Birebir ders atmosferi — geniş | Horizontal |
| Enstrüman detayları | Kare |

---

## 4. Keman Eğitimi

| Shot | Format |
|------|--------|
| Yay / el / tel detayları | Kare / horizontal |
| Eğitmen ve öğrenci — birebir | 4:3 |
| Grup keman dersi (varsa) | Horizontal |
| Dikey portre — öğrenci + keman | 4:5 |
| Enstrüman detayı | Kare |

---

## 5. Gitar Eğitimi

| Shot | Format |
|------|--------|
| Parmak / tel / klavye detayları | Horizontal |
| Birebir ders atmosferi | 4:3 |
| Grup dersi (varsa) | Horizontal |
| Environmental portrait — öğrenci + gitar | 4:5 |
| Enstrüman detayı | Kare |

---

## 6. Eğitmen Portreleri

Her eğitmen için:

| Shot | Format |
|------|--------|
| Baş–omuz portre | 4:5 dikey |
| Environmental portrait — sınıf ortamı | 3:2 horizontal |
| Ders sırasında candid | 4:3 |
| Yatay crop (banner için) | 16:9 |

Işık: Doğal veya soft box. Nötr, doğal expression.  
Arka plan: Akademi içi, sade.

---

## 7. Etkinlikler (Gerçekleştiğinde)

- Sergi açılışı ve eserler
- Öğrenci konseri / sahne
- Sahne genel + detay
- İzleyici / veli katılımı
- Öğrenciler performans sırasında

---

## Notlar

- Çocukların yüzlerinin görünür olduğu tüm görseller için **yazılı veli onayı** zorunludur.
- Onay formları arşivlenmelidir.
- Sentetik / yapay zeka üretimi görseller gerçek akademi görseli olarak kullanılmamalıdır.
